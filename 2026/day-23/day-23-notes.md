Git Branching & Working with GitHub
---------------------------------------------
Task1: Understanding Branches

1) What is a branch in Git?
   A branch is like making a copy of your project so you can safely make changes.
2)Why do we use branches instead of committing everything to main?
  We use branches to make changes safely without breaking the main project.
3)What is HEAD in Git?
  HEAD shows which branch you are currently working on and points to the latest commit of that branch.
4)What happens to your files when you switch branches?
  Your project files automatically change to the version saved in that branch.
